# Autres appareils

Pour **chaque** autre tablette ou téléphone (hôtesses comprises) :

1. Ouvrez la **même adresse de l'application**.
2. Écran **Connexion** : le **même identifiant** et le **même mot de passe** que la
   caisse centrale, puis **Connexion**. C'est la caisse centrale qui les tape : les
   hôtesses n'ont pas besoin de les connaître.
3. Ajoutez l'application sur l'**écran d'accueil**, pour l'ouvrir d'un geste :
   - **iPad / iPhone (Safari)** : bouton **Partager** (carré avec une flèche) →
     **Sur l'écran d'accueil** → **Ajouter** ;
   - **Android (Chrome)** : menu **⋮** → **Ajouter à l'écran d'accueil** →
     **Ajouter**.

> 📷 **Capture** : l'écran « Connexion » (application).
> 📷 **Capture** : « Sur l'écran d'accueil » sur iPad, et sur Android.

## Bon à savoir
- **La connexion se termine chaque nuit à 3 h** : le matin, la caisse centrale
  reconnecte chaque appareil (le navigateur remplit l'identifiant et le mot de passe).
- **Safari** (Mac) et **tous les navigateurs d'iPad et d'iPhone** oublient la
  connexion quand on les ferme : il faut alors se reconnecter.
- Ouvrez toujours l'adresse qui finit par **`/exec`** (favori ou écran d'accueil),
  jamais une adresse en `…googleusercontent.com` proposée par l'historique.
- Ne vous connectez **jamais** au compte Google du magasin sur une tablette de caisse.
- **Appareil perdu ou volé, départ d'une personne** : changez le mot de passe du
  compte (**⚙️ → Code & compte**). Tous les appareils sont alors déconnectés ;
  reconnectez-les avec le nouveau mot de passe.
- **Trop d'erreurs de mot de passe** : après une erreur, le bouton attend 10 s. À
  partir de 10 erreurs, la connexion est bloquée 5, puis 10, puis 15 minutes (jamais
  plus). Les appareils déjà connectés continuent de fonctionner.
