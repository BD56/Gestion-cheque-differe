# Régler l'offre

Sur l'appareil de la caisse centrale : touchez **⚙️** (en haut à droite), tapez le
code responsable, **Déverrouiller**. L'**espace responsable** s'ouvre ; le menu est à
gauche.

## Réglages de la structure
À gauche, **Réglages** :

| Champ | Exemple | À savoir |
|---|---|---|
| **Nom de la structure, avec l'article** | « l'Hypermarché X », « la société Y » | **À remplacer** : le nom proposé est celui d'un autre magasin. Il apparaît dans les mentions légales (« L'auteur concède à … »). |
| **Nom de l'offre** | « Chèques différés de Noël » | Affiché sous le titre. |
| **Titre de l'onglet du navigateur** | « Caisse - Saisie Chèques » | |
| **Libellé du montant** | « Montant » | Case **Montant obligatoire** : cochée, la saisie exige un montant. |
| **Libellé du champ Notes** | « Notes ou Infos » | |
| **Précision du champ Notes** | « numéro de caisse, etc. » | Facultatif, affiché entre parenthèses. |
| **Passages autorisés par client et par offre** | 1 | 1 = un seul chèque par client. Jusqu'à 10. |

Touchez **Enregistrer les réglages**.

> 📷 **Capture** : l'écran « Réglages de la structure » (application).

## Dates de l'offre
À gauche, **Opération** :

1. **Début** et **Fin** : les dates de l'offre.
2. Touchez **Mettre à jour les dates**.

En dehors de ces dates, la saisie est fermée : le haut de l'écran indique
« Opération à venir », « Opération terminée » ou « Aucune opération en cours ». La
nuit qui suit le dernier jour, le robot de nuit **clôture** l'offre : les saisies partent dans
les **Archives**.

> 📷 **Capture** : l'écran « Opération » (application).

## Mode de sécurité
À gauche, **Sécurité** :

- **Signaler** (au départ) : en cas de doublon, l'alerte s'affiche, mais l'hôtesse
  peut enregistrer quand même, après une confirmation (la ligne est marquée).
- **Bloquant** : la fraude et l'anomalie grave sont **refusées** ; seul l'homonyme
  peut être enregistré, après vérification d'une deuxième pièce.

Le mode reste le même d'une offre à l'autre.
