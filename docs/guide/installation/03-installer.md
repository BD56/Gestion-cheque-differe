# Installer

Dans **votre copie** du Google Sheets :

1. Attendez quelques secondes : un menu **🚀 APPLICATION** apparaît en haut, à droite
   de « Aide ». *(Pas de menu ? Rechargez la page.)*
2. Cliquez sur **🚀 APPLICATION → 🧰 Installer / vérifier l'installation**.
3. Google demande votre autorisation (une seule fois) :
   1. **Autorisation requise** → **OK** (ou **Continuer**) ;
   2. choisissez le **compte Google du magasin** ;
   3. « Google n'a pas validé cette application » : c'est **normal** pour un
      programme fait pour un seul établissement. Cliquez sur **Paramètres avancés**,
      puis sur **Accéder à … (non sécurisé)** ;
   4. si Google propose des cases à cocher, cochez **Tout sélectionner** ;
   5. cliquez sur **Autoriser** (ou **Continuer**).
4. Si rien d'autre ne se passe, cliquez **une seconde fois** sur **🧰 Installer /
   vérifier l'installation** (la première fois, Google s'arrête parfois après
   l'autorisation).
5. Une fenêtre **🧰 Installation** affiche le compte rendu. Lisez-le jusqu'au bout.

> 📷 **Capture** : le menu 🚀 APPLICATION ouvert.
> 📷 **Capture** : chacun des écrans d'autorisation de Google (3 à 5 écrans).
> 📷 **Capture** : la fenêtre du compte rendu (avec le code d'activation masqué).

## Ce que dit le compte rendu
- « Nouvelle copie détectée : … effacés » : normal, votre copie repart à neuf.
- « Déclencheur créé : clôture automatique … » : le **robot de nuit** est en place.
  Chaque nuit, il clôture l'offre terminée et supprime les données trop anciennes.
- « Version … » : le numéro de la version installée.
- **🔑 Code d'activation : 1234-5678** (8 chiffres) : **notez-le**, il sert au
  chapitre « Première connexion ». Il est valable **24 heures** et une seule fois.
  Ne le donnez qu'à la caisse centrale.

> **Si ça ne marche pas**
> - *« ⚠️ INSTALLATION INCOMPLÈTE »* : la copie n'est pas complète. Ne continuez pas ;
>   envoyez une capture du compte rendu à l'auteur.
> - *Code d'activation expiré ou perdu* : menu **🚀 APPLICATION → 🔑 Code
>   d'activation** en affiche un nouveau (tant que le compte du magasin n'est pas
>   créé).
> - *Plus aucune fenêtre ne s'ouvre* : votre navigateur bloque les fenêtres
>   surgissantes ; autorisez-les pour docs.google.com.
