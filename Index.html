❓ Guide d'utilisation et Aide

  • Quelle face ? Le côté qui porte la bande de symboles <<< (en bas du document). Sur les cartes (CNI, titre de séjour), c'est en général le dos ; sur le passeport, la page avec la photo.
  • Comment faire : touchez 📷 (en haut), photographiez cette bande bien à plat → le Nom, le Prénom et le N° de pièce se remplissent tout seuls.
  • Pièces reconnues : Passeport, Nouvelle carte d'identité, Ancienne carte d'identité, Titre de séjour. (Ne fonctionne pas avec la Carte Vitale ni le permis de conduire.)
  • Pour une bonne lecture : la bande doit remplir la largeur, être nette, bien éclairée, sans reflet, et dans le sens de lecture.
  • ⚠️ Vérifiez toujours : relisez le Nom, le Prénom et le N° de pièce, et corrigez si besoin avant de valider.
  • Si ça ne marche pas : reprenez la photo ou saisissez à la main. Le scan est une aide, pas une obligation.
  • 1ᵉʳ usage : le tout premier scan prend quelques secondes (chargement du lecteur), ensuite c'est rapide.
  • Comment faire : Remplissez les informations du formulaire, puis cliquez sur Valider.
  • 🟢 Bandeau Vert : Saisie acceptée et enregistrée. Aucun doublon détecté.
  • 🟠 Bandeau Orange (Homonyme possible) : Le système a détecté le même Nom, mais avec une Pièce d'identité différente.
  • 🔴 Bandeau Rouge (Doublon ou Usurpation) : Ce Numéro de Pièce a déjà été enregistré (soit par le même client, soit sous un nom différent).
  • 🔁 Plusieurs passages autorisés : si le réglage le permet (⚙️ → Réglages, « Passages autorisés par client »), un même client (même nom + même pièce) peut revenir jusqu'à ce nombre ; ses passages sont notés « ℹ️ Passage 2/3 ». Au-delà : doublon. Une pièce sous un autre nom, ou le même nom avec une autre pièce, reste toujours signalé.
  • Doublon sur l'offre en cours : dès que tu saisis le N° de pièce (puis passes au champ suivant), s'il est déjà enregistré sur cette offre, une fenêtre t'avertit et montre la ligne concernée. Tu peux corriger ou continuer — la décision finale reste à la validation.
  • Client déjà venu (offres précédentes) : si le numéro est connu d'une offre passée, le Nom et le Prénom se pré-remplissent automatiquement (ou une fenêtre te le propose, selon le réglage ⚙️). Vérifie toujours avec le document avant de valider.

Dans l'espace responsable (⚙️, code responsable), vous définissez la rigueur du système :

  • 🟡 Mode SIGNALER : Souple. L'application vous alerte (Orange ou Rouge) mais vous laisse le bouton pour "Forcer" la validation manuellement.
  • 🔴 Mode BLOQUANT : Strict. En cas d'alerte Rouge (doublon ou pièce déjà utilisée), la saisie est refusée : aucun bouton pour forcer.
  • Libre pour tous : la saisie et l'impression (⚙️, en haut).
  • Avec le code responsable : mode de sécurité, dates de l'offre, corrections, archives, réglages, clôture.
  • 1ʳᵉ utilisation : l'application demande de choisir le code (6 chiffres).
  • Tablettes autorisées : chaque tablette doit être autorisée une fois par un responsable (avec le code). Une tablette non autorisée ne voit rien, même avec le lien. Liste et retrait : ⚙️ → Espace responsable → 🔑 Code & tablettes.
  • Sécurité : l'espace se reverrouille à la fermeture du panneau ou après 10 min sans action. Après un code faux, il faut patienter 10 s ; 5 codes faux bloquent 15 min.
  • Code oublié : il se réinitialise depuis le panneau ⚙️ du Google Sheets (réservé aux personnes qui ont accès au fichier).
  • Lancer ou modifier : Cliquez sur ⚙️, ouvrez l'espace responsable puis la tuile 📅 Opération. S'il y a une erreur ou une prolongation, modifiez simplement la date de fin ici.
  • Fin de l'offre (Auto-Pilote) : Vous n'avez rien à faire ! L'opération se clôture, s'archive et verrouille la tablette toute seule la nuit suivant le dernier jour.
  • Corriger ou supprimer une saisie : ⚙️ → espace responsable → tuile 📋 Saisies. Recherchez la ligne par nom ou n° de pièce. Une correction est re-vérifiée (doublon, usurpation, homonyme) comme une nouvelle saisie.
  • Imprimer le jour actuel : Cliquez sur ⚙️ puis sur le bouton bleu 🖨️ IMPRIMER AUJOURD'HUI pour sortir la liste des saisies du jour.
  • Imprimer un jour oublié : Toujours dans ⚙️, utilisez le calendrier "Imprimer un jour précédent" pour sortir la liste d'une journée passée.
  • Imprimer une ancienne offre clôturée : ⚙️ → espace responsable → tuile 🗄️ Archives, choisissez l'offre puis imprimez.
