# Vérifier

Faites ces essais **pendant les dates de l'offre**, avec des noms inventés, puis
effacez-les. Cochez au fur et à mesure.

## Le jour de l'installation
- [ ] **Saisie d'essai** : sur une tablette, N° de pièce `ESSAI0001`, nom `ESSAI`,
      prénom `UN`, un montant, puis **Enregistrer**. Un message confirme
      l'enregistrement.
- [ ] **Doublon d'essai** : de nouveau `ESSAI0001`, `ESSAI`, `UN`. L'alerte
      **ALERTE FRAUDE** s'affiche (en mode Signaler) : touchez **Ne pas
      enregistrer**.
- [ ] **Anomalie d'essai** : `ESSAI0001` avec le nom `AUTRE`. L'alerte **ANOMALIE
      GRAVE** s'affiche : **Ne pas enregistrer**.
- [ ] **Suppression** : **⚙️** → code → à gauche **Saisies** → sur la ligne
      `ESSAI`, **Supprimer**, puis **Confirmer la suppression**.
- [ ] **Deuxième appareil** : il voit l'offre et peut saisir (sans rien enregistrer
      cette fois, ou en supprimant ensuite).
- [ ] **Accès** : dans le Google Sheets, bouton **Partager** (en haut à droite). Seuls
      la direction / le manager y figurent.

> 📷 **Capture** : l'alerte « ALERTE FRAUDE » sur la tablette (application).

## Le lendemain matin
- [ ] Les appareils demandent de **se reconnecter** (fin de connexion à 3 h) :
      normal.
- [ ] **Robot de nuit** : **⚙️** → code → **Vue d'ensemble**. **Aucun** message
      « Robot de nuit absent » ou « Le robot de nuit n'a pas fonctionné ».

> **Si ça ne marche pas**
> - *« Robot de nuit absent »* : dans le Google Sheets, **🚀 APPLICATION → 🧰
>   Installer / vérifier l'installation**.
> - *La saisie est impossible* (« Aucune opération en cours ») : vérifiez les dates
>   (chapitre « Régler l'offre »).
> - *Pas d'alerte au doublon d'essai* : arrêtez-vous et prévenez l'auteur ; ne lancez
>   pas l'offre.

Tout est coché ? L'installation est **terminée**.
