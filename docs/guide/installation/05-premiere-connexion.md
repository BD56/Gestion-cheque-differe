# Première connexion

À faire **avec la caisse centrale**, sur **son appareil** (tablette ou téléphone).
Ayez sous la main le **code d'activation** (chapitre « Installer ») et l'**adresse de
l'application** (chapitre « Mettre en ligne »).

## 1. Créer le compte du magasin
1. Sur l'appareil de la caisse centrale, ouvrez l'**adresse de l'application**.
2. L'écran **Première installation** s'affiche.
3. **Code d'activation** : tapez ou collez les 8 chiffres.
4. **Identifiant** : par exemple « Caisse centrale ».
5. **Mot de passe** : 8 caractères au moins, puis de nouveau dans **Confirmer le mot
   de passe**.
6. Touchez **Créer le compte**.
7. Si le navigateur propose d'**enregistrer le mot de passe**, acceptez : il le
   proposera à chaque connexion.

Ce compte est **le même sur tous les appareils** du magasin. Sans le code
d'activation, personne ne peut le créer, même avec l'adresse.

> 📷 **Capture** : l'écran « Première installation » (application).

## 2. Choisir le code responsable (obligatoire)
L'écran **Compte créé** demande comment protéger l'**espace responsable** (corrections,
suppressions, impression, dates). Deux choix, aucun n'est fait d'avance :

- **Un code commun** : un seul code de 6 chiffres, connu des personnes de la caisse
  centrale. Tapez-le deux fois, puis **Enregistrer le code**.
- **Des codes personnels** : chaque personne a **son** code de 6 chiffres ; le
  journal note **qui** a fait quoi. Tapez **votre nom**, votre code deux fois, puis
  **Enregistrer mon code**. Les autres personnes s'ajoutent ensuite (voir plus bas).

> 📷 **Capture** : l'écran « Compte créé » avec les deux choix (application).

> 💡 **Lequel choisir ?**
>
> | | Code commun | Codes personnels |
> |---|---|---|
> | Mise en place | 1 minute | chaque personne tape son code devant vous |
> | Départ d'une personne | changer le code, le redonner à tous | retirer la personne, c'est tout |
> | Le journal note… | le compte du magasin | le **nom** de la personne |
>
> Petite équipe stable : code commun. Équipe nombreuse ou qui tourne, ou si vous
> voulez savoir qui a corrigé ou supprimé une saisie : **codes personnels**.
> Vous pourrez changer d'avis plus tard.

## 3. Ajouter les autres personnes (codes personnels seulement)
1. Touchez **⚙️** (en haut à droite), choisissez votre nom, tapez votre code,
   **Déverrouiller**.
2. À gauche, **Code & compte**.
3. Sous **Ajouter une personne** : son nom (deux personnes ne peuvent pas avoir le
   même nom : écrivez « Marie D. » et « Marie L. »).
4. **La personne tape elle-même** son code, deux fois, devant vous, puis
   **Ajouter**.

> **Si ça ne marche pas**
> - *« Code d'activation » refusé* : vérifiez les 8 chiffres ; s'il a plus de 24 h,
>   affichez-en un nouveau dans le Google Sheets (**🚀 APPLICATION → 🔑 Code
>   d'activation**).
> - *L'écran affiche « Connexion » au lieu de « Première installation »* : le compte
>   existe déjà. Connectez-vous avec son identifiant et son mot de passe.
> - *Mot de passe oublié, plus personne ne peut entrer* : dans le Google Sheets,
>   **🚀 APPLICATION → ⚙️ Ouvrir le panneau de contrôle**. Ce panneau permet de
>   **réinitialiser le code responsable**, ou de **réinitialiser le compte**. Dans ce
>   second cas, un nouveau code d'activation s'affiche, et l'application revient à la
>   « Première installation ».
