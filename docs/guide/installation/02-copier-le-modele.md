# Copier le modèle

Sur l'**ordinateur**, connecté au **compte Google du magasin** :

1. Ouvrez le **lien de copie** donné par l'auteur (il finit par `/copy`).
2. Google affiche « Copier le document ». Dans **Nom**, écrivez par exemple
   « Gestion Chèques — Magasin X ».
3. Cliquez sur **Créer une copie**.

La copie s'ouvre : c'est **votre** Google Sheets. Le programme de l'application est
copié avec lui. Mettez-le en favori, vous en aurez besoin.

> 📷 **Capture** : la fenêtre « Copier le document » avec le bouton « Créer une copie ».

> **Si ça ne marche pas**
> - *Google demande de se connecter, ou la copie part sur un autre compte* : vous
>   avez plusieurs comptes Google dans ce navigateur. Ouvrez une **fenêtre de
>   navigation privée**, connectez-vous **seulement** au compte du magasin, puis
>   rouvrez le lien.
> - *« Vous avez besoin d'une autorisation »* : le lien n'est pas le bon. Demandez-le
>   de nouveau à l'auteur.
