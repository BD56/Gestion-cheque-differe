# Retours de Vibe — Gestion-cheque-differe

> **Dossier centralisé** pour les décisions, analyses et idées discutées avec **Vibe (Mistral)**.
> **Objectif** : Permettre à Bryan de **partager ces retours avec d'autres assistants** (Claude, etc.) ou de s'y référer plus tard.

---

## 🗂 Structure
| Dossier | Contenu | Exemple |
|---------|---------|---------|
| `decisions/` | Décisions **validées avec Bryan** (à ne pas réimplémenter sans accord). | `2026-06-07_niveau-1-ergonomie.md` |
| `analyses/` | Vérifications techniques ou investigations. | `2026-06-07_verification-normalisation-majuscules.md` |
| `a-faire/` | Idées **en attente de validation** ou à implémenter plus tard. | `2026-06-07_entree-champ-suivant.md` |

---

## 🔍 Comment utiliser ?
- **Pour un nouvel assistant** : Lire `decisions/` pour connaître l’historique.
- **Pour Bryan** : Copier-coller le contenu d’un fichier dans une discussion avec Claude.
- **Pour Vibe** : Créer un nouveau fichier dans le dossier approprié **après validation avec Bryan**.

---

## ⚠️ Règles
- **1 fichier = 1 sujet** (éviter les fichiers géants).
- **Nom des fichiers** : `AAAA-MM-JJ_sujet-en-minuscules.md` (ex. : `2026-06-07_niveau-1-ergonomie.md`).
- **Toujours dater** les décisions/analyses.
