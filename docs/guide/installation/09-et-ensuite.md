# Et ensuite

- **Tous les jours** : tout se fait dans l'application (saisie, corrections,
  impression, archives). Le Google Sheets ne sert que de rangement : n'y modifiez
  rien à la main. Voir le **mode d'emploi** *(à venir)*.
- **Une difficulté** (mot de passe oublié, tablette déconnectée, message inattendu) :
  voir les fiches **En cas de problème** *(à venir)*.
- **Nouvelle offre** : après la clôture, réglez simplement les nouvelles dates
  (**Opération**). Les réglages et le mode de sécurité sont gardés.
- **Mise à jour de l'application** : rare, annoncée par l'auteur. Voir le **guide
  technique** *(à venir)*. Ne refaites jamais un « Nouveau déploiement ».
- **Changement de manager** (départ, mutation, retraite) :
  - Google Sheets sur un **compte du magasin** : remettez le mot de passe et les codes
    de secours à votre successeur, qui change aussitôt le mot de passe. C'est tout.
  - Google Sheets sur un **compte personnel** : à faire **avant** le départ, menu
    **🚀 APPLICATION → 🔁 Passer la main (changement de manager)**, puis suivez les
    indications de la fenêtre.
