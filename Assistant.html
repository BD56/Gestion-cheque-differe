Mettre l'application en ligne

Google demande de faire cette étape vous-même. Le bouton ouvre la bonne page ; faites ces 6 clics, puis revenez ici.

  1. En haut à droiteDéployer ▾

  3. Roue dentée ⚙️, puisApplication Web
  4. Exécuter en tant queMoi
  5. Qui a accèsTout le monde
  6. En bas à droiteDéployer

Si Google redemande une autorisation, acceptez-la comme au début. Ne choisissez pas « Utilisateur accédant à l'application Web » : chaque tablette aurait besoin d'un compte Google.

Connecter la tablette de la caisse centrale

L'application n'est pas encore en ligne. Menu 🚀 APPLICATION → ▶ Assistant d'installation.

Sur la tablette, ouvrez l'appareil photo et visez ce code : l'application s'ouvre.

Ou ouvrez ce lien sur la tablette (envoyez-le par e-mail ou message) :

Sur l'écran « Première installation », tapez le code d'activation :

Valable 24 h, une seule fois. Ne le donnez qu'à la caisse centrale. Puis créez le compte du magasin (identifiant et mot de passe, les mêmes sur tous les appareils) et choisissez le code responsable.

Le compte du magasin existe : sur chaque appareil, connectez-vous avec son identifiant et son mot de passe.

En attente de la tablette : l'assistant verra la création du compte du magasin.
✓ Le compte du magasin est créé : la tablette est connectée. Les autres appareils : même QR code ou même lien, puis l'identifiant et le mot de passe du magasin.
La tablette demande de se connecter à Google ?

« Qui a accès » n'est pas sur « Tout le monde ». Dans Apps Script : Déployer → Gérer les déploiements → crayon ✏️ → Qui a accès : Tout le monde → Déployer. L'adresse ne change pas.

L'application est installée

L'onglet « Démarrer » va disparaître. Pour retrouver le lien et le QR code des tablettes : menu 🚀 APPLICATION → 📱 Connecter une tablette.

Il reste à régler l'offre et ses dates dans l'application (espace responsable → Opération). Demain matin, l'espace responsable confirmera que le robot de nuit est passé.
