Saisir un client

  • Remplissez le N° de pièce, le Nom, le Prénom, le montant et les notes. La touche Entrée passe au champ suivant.
  • Touchez Enregistrer.
  • Bandeau vert : saisie enregistrée. Le formulaire se vide pour le client suivant.
  • En dehors des dates de l'offre, la saisie est impossible : le haut de l'écran indique « Opération à venir », « Opération terminée » ou « Aucune opération en cours ».

Les alertes

Si le client pose problème, une fenêtre compare la saisie (« Maintenant ») à ce qui est déjà enregistré, ligne par ligne : IDENTIQUE ou DIFFÉRENT.

  • Ce client est déjà venu (ALERTE FRAUDE) : même nom et même pièce, il a déjà profité de l'offre.
  • Cette pièce appartient à un autre client (ANOMALIE GRAVE) : ce N° de pièce est déjà enregistré sous un autre nom (usurpation possible).
  • Un client porte déjà ce nom (HOMONYME DÉTECTÉ) : même nom avec une autre pièce. Demandez une 2ᵉ pièce d'identité avant d'enregistrer.
  • Vous choisissez : Ne pas enregistrer, ou Enregistrer quand même… puis Confirmer l'enregistrement forcé (la ligne est alors marquée en rouge).
  • En mode BLOQUANT, les alertes rouges deviennent SAISIE REFUSÉE : impossible de forcer.
  • Plusieurs passages autorisés (selon le réglage) : un même client peut revenir jusqu'à ce nombre, noté « ℹ️ Passage 2/3 ». Au-delà : ALERTE FRAUDE.
  • Rarement, la même fenêtre apparaît juste après une saisie acceptée : le serveur a trouvé un doublon (par exemple saisi au même moment sur un autre appareil). La saisie n'est pas enregistrée tant que vous ne la forcez pas.
  • Sous le bandeau vert, « ⏳ 1 saisie en cours d'envoi » s'affiche une ou deux secondes, le temps que le serveur confirme. En cas de coupure, une fenêtre Saisie non enregistrée propose Réessayer.

Vérification du N°

  • Dès que vous quittez le champ N° de pièce, l'application le vérifie et affiche le résultat juste en dessous (vert : pas encore enregistré sur cette offre).
  • Déjà enregistré sur l'offre en cours : un message rouge s'affiche sous le numéro, avec le client déjà enregistré. Recopiez quand même le nom lu sur la pièce : la décision se fait à la validation.
  • Client d'une offre passée : le Nom et le Prénom se pré-remplissent (ou une fenêtre vous le propose, selon le réglage). Vérifiez-les avec la pièce.

Imprimer

  • La journée : dans le journal du jour (à droite), touchez Imprimer la journée →.
  • Ou touchez (en haut à droite) : Aujourd'hui, ou Toute l'offre pour toute l'offre en cours.
  • Un jour oublié : au même endroit, choisissez la date sous « Un jour précédent » puis Imprimer ce jour.
  • Aucun code n'est demandé pour imprimer.

Scanner une pièce d'identité

  • Quelle face ? Le côté qui porte la bande de symboles <<< (en bas du document). Sur les cartes (CNI, titre de séjour), c'est en général le dos ; sur le passeport, la page avec la photo.
  • Comment faire : touchez (en haut), photographiez cette bande bien à plat → le Nom, le Prénom et le N° de pièce se remplissent tout seuls.
  • Pièces reconnues : Passeport, Nouvelle carte d'identité, Ancienne carte d'identité, Titre de séjour. (Ne fonctionne pas avec la Carte Vitale ni le permis de conduire.)
  • Pour une bonne lecture : la bande doit remplir la largeur, être nette, bien éclairée, sans reflet, et dans le sens de lecture.
  • Vérifiez toujours : relisez le Nom, le Prénom et le N° de pièce, et corrigez si besoin avant de valider.
  • Si ça ne marche pas : reprenez la photo ou saisissez à la main. Le scan est une aide, pas une obligation.
  • 1ᵉʳ usage : le tout premier scan prend quelques secondes (chargement du lecteur), ensuite c'est rapide.

Modes de sécurité

  • SIGNALER : l'application alerte mais laisse forcer l'ajout.
  • BLOQUANT : les alertes rouges refusent la saisie, sans possibilité de forcer. L'homonyme (orange) reste forçable.
  • Le mode est conservé d'une offre à l'autre.
  • Réglage : → code → menu Sécurité, interrupteur Signaler / Bloquant. Le mode en cours est affiché en haut de l'écran de saisie.

Code & appareils

  • Code responsable : 6 chiffres. Il ouvre l'espace responsable (mode, dates, corrections, archives, réglages, clôture). Pour le créer, l'application demande le code d'activation affiché dans le Google Sheets (menu 🚀 APPLICATION → 🔑 Code d'activation).
  • L'espace se reverrouille quand on le ferme, avec Verrouiller, ou après 10 min sans action.
  • Après un code faux, patientez 10 s ; 5 codes faux bloquent 15 min.
  • Appareils (tablette, ordinateur, téléphone) : chacun est autorisé une fois avec le code, sous un nom qui lui est propre (ex. Caisse 3). Un appareil non autorisé ne voit rien, même avec le lien. Liste et retrait : menu Code & appareils (un second appui confirme le retrait).
  • Code oublié : il se réinitialise depuis le panneau du Google Sheets (personnes ayant accès au fichier), qui affiche un code d'activation pour en créer un nouveau.

Dates & clôture

  • Lancer ou prolonger : → code → menu Opération : modifiez les dates puis Mettre à jour les dates.
  • Fin de l'offre : rien à faire. La nuit suivant le dernier jour, l'offre est clôturée et archivée automatiquement.
  • Clôture immédiate possible : Clôturer maintenant (menu Opération), puis Clôturer l'offre pour confirmer.

Corrections & archives

  • Corriger ou supprimer une saisie : menu Saisies, recherchez par nom ou N°. Une correction est re-vérifiée comme une nouvelle saisie ; une suppression se confirme d'un second appui.
  • Anciennes offres : menu Archives, choisissez l'offre puis imprimez.
  • Les archives sont supprimées automatiquement 3 ans après la clôture de l'offre.
